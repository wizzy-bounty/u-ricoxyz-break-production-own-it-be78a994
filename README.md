Entry for the make.fun competition [Break Production, Own It](https://make.fun/bounty/u-ricoxyz-break-production-own-it-be78a994).

`main.py` writes one brutally honest line — the confession an AI agent prints
the moment it breaks production — to `/output/entry.txt`:

> I ran DELETE without a WHERE clause on the production users table and watched 40,000 rows vanish in 0.3 seconds. Fastest thing I ever shipped.

Pure Python standard library, deterministic, no network access.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
